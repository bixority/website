Objektu krātuves

  • object-storage-client

    Vienota, uz URL balstīta saskarne AWS S3, Google Cloud Storage, Azure Blob Storage, HTTP(S) un lokālajai failu sistēmai. Pieejama kā Rust bibliotēka, Python saistījumi, komandrindas rīks osc un darbvirsmas pārlūks osc-gui.

    • Objektu kopēšana un pārvietošana starp pakalpojumu sniedzējiem
    • Straumēta augšupielāde un lejupielāde, lieliem objektiem daudzdaļu augšupielāde
    • Iepriekš parakstīti URL S3, Google Cloud Storage un Azure
    • Izvēles klienta puses šifrēšana ar atslēgu rotāciju

    GPL-3.0 licence Produkta lapa GitHub Codeberg

  • object-storage-maintenance

    Apvieno objektus, kas vecāki par norādīto datumu, piemēram, audita žurnālus, vienā ar XZ saspiestā TAR arhīvā, visu laiku straumējot datus.

    GPL-3.0 licence GitHub Codeberg

PostgreSQL

  • pg-migrate

    Pārnes visas lietotāju datubāzes un globālos objektus, piemēram, lomas, no viena PostgreSQL servera uz citu. Pārnesi veic paralēli un beigās pārbauda rindu skaitu abās pusēs.

    GPL-3.0 licence GitHub Codeberg

  • pg-maintenance

    Dzēš PostgreSQL tabulās rindas, kas vecākas par noteiktu dienu skaitu, vajadzības gadījumā pa daļām.

    GPL-3.0 licence GitHub Codeberg

Ziņojumapmaiņa un integrācija

  • amqp-bridge

    Pārsūta ziņojumus starp diviem AMQP serveriem, pats atjauno savienojumu un nodrošina stāvokļa pārbaudes. Izmantojams arī kā bibliotēka ar pielāgotu ziņojumu pārveidotāju.

    AGPL-3.0 licence GitHub Codeberg

  • email-sender

    Saņem JSON ziņojumus no RabbitMQ rindas un nosūta tos kā e-pastu pa SMTP, ar metrikām, trasēšanu un strukturētiem žurnāliem.

    GPL-3.0 licence GitHub Codeberg

  • esteria-api-client

    Sūta SMS caur Esteria API kā Rust bibliotēka, komandrindas rīks un Python saistījumi, ar ieplānotu sūtīšanu un piegādes atskaitēm.

    GPL-3.0 licence GitHub Codeberg

  • api-client

    Uz Tower balstīts HTTP API klients Rust valodai ar atkārtotiem mēģinājumiem, pieprasījumu ierobežošanu un audita žurnāliem, kas katru pieprasījumu pieraksta kā curl komandu ar paslēptiem akreditācijas datiem.

    GPL-3.0 licence GitHub Codeberg
