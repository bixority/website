Open-source tools

We publish the tools we build for our own work. All eight are written in Rust, licensed as free software, and available on GitHub and Codeberg.

Object storage

object-storage-client

One URL-based API for AWS S3, Google Cloud Storage, Azure Blob Storage, HTTP(S) and the local filesystem. It ships as a Rust library, Python bindings, the osc command line and the osc-gui desktop browser.

  • Copy and move objects between providers
  • Streaming uploads and downloads, with multipart uploads for large objects
  • Pre-signed URLs for S3, Google Cloud Storage and Azure
  • Optional client-side encryption, with key rotation

GPL-3.0 license

Product page GitHub Codeberg

object-storage-maintenance
Gathers objects older than a given date, such as audit logs, into a single TAR archive compressed with XZ, streaming the whole way.
GPL-3.0 license GitHub Codeberg

PostgreSQL

pg-migrate
Moves every user database and the global objects, such as roles, from one PostgreSQL server to another. It runs dumps and restores in parallel and checks row counts on both sides.
GPL-3.0 license GitHub Codeberg
pg-maintenance
Deletes rows older than a set number of days from PostgreSQL tables, in batches if needed.
GPL-3.0 license GitHub Codeberg

Messaging and integration

amqp-bridge
Forwards messages between two AMQP servers, reconnects on its own and exposes health checks. Also usable as a library with a custom message transformer.
AGPL-3.0 license GitHub Codeberg
email-sender
Takes JSON messages from a RabbitMQ queue and sends them as email over SMTP, with metrics, tracing and structured logs.
GPL-3.0 license GitHub Codeberg
esteria-api-client
Sends SMS through the Esteria API, as a Rust library, a command-line tool and Python bindings, with scheduled sending and delivery reports.
GPL-3.0 license GitHub Codeberg
api-client
An HTTP API client for Rust built on Tower, with retries, rate limiting and audit logs that record each request as a curl command with credentials redacted.
GPL-3.0 license GitHub Codeberg
