Programmatūra un infrastruktūra, ko projektē, izstrādā un uztur viena komanda.

Bixority ir inženierijas uzņēmums Rīgā. Kopš 2010. gada strādājam DevOps, SRE un programmatūras izstrādes jomā, un par paveikto atbildam arī pēc nodošanas ekspluatācijā.

Mūsu pakalpojumi Atvērtā koda rīki

Ko mēs darām

  • DevOps un SRE

    Projektējam, automatizējam un uzturam platformas, uz kurām darbojas jūsu programmatūra, no pirmā klastera līdz dežūrām.

    • Kubernetes jūsu infrastruktūrā un EKS, AKS, GKE
    • Infrastruktūra kā kods
    • CI/CD un laidienu inženierija
    • Novērojamība un reaģēšana uz incidentiem
    • Datubāzu uzturēšana: migrācijas, rezerves kopijas, apkope
    Sīkāk par pakalpojumiem

  • Programmatūras izstrāde

    Vedam produktu no arhitektūras līdz uzturēšanai, izmantojot Rust, Python un TypeScript. Katra izmaiņa tiek testēta un pārskatīta pirms izlaišanas.

    Kā mēs izstrādājam programmatūru

  • Atvērtā koda rīki

    Publicējam rīkus, ko radām savam darbam: piekļuvi objektu krātuvēm, PostgreSQL migrāciju un apkopi, ziņojumu pārsūtīšanu. Tie visi ir brīvā programmatūra ar GPL vai AGPL licenci.

    Skatīt projektus

Viena komanda no projektēšanas līdz ekspluatācijai

Tie paši cilvēki, kas sistēmu projektē, to arī izstrādā un uztur. Nekas nepazūd, nododot darbu tālāk, un neviens nevar teikt, ka problēma ir kāda cita atbildībā.

  1. Projektēšana

    Izvērtējam esošo situāciju, nosaucam riskus un pirms darba sākšanas rakstiski piedāvājam arhitektūru un plānu.

  2. Izstrāde

    Katra izmaiņa tiek testēta un pārskatīta. Lēmumus dokumentējam tur, kur nākamais inženieris tos meklēs.

  3. Uzturēšana

    Uzraugām izveidoto, reaģējam uz incidentiem un regulāri atjauninām sistēmas arī ilgi pēc palaišanas.

Kvalitāte praksē

“Because quality matters” (jo kvalitātei ir nozīme) ir princips, uz kura dibināts Bixority. Tas attiecas uz katru darba daļu: kodu, infrastruktūru, sistēmu ekspluatāciju un to, kā mēs sazināmies.

Testēts un pārskatīts
Izmaiņas tiek izlaistas tikai pēc automatizētiem testiem un kolēģa pārskata.
Atvērts pēc noklusējuma
Publicējam savus rīkus un dokumentējam, ko tie dara un ko nedara.
Veidots atkopties
Sistēmas projektējam tā, lai tās droši pārdzīvotu kļūmes un atkoptos bez varoņdarbiem.

Atvērtā koda rīki

Astoņi projekti, visi rakstīti Rust valodā un publicēti GitHub un Codeberg.

object-storage-client

Vienota, uz URL balstīta saskarne AWS S3, Google Cloud Storage, Azure Blob Storage, HTTP(S) un lokālajai failu sistēmai. Pieejama kā Rust bibliotēka, Python saistījumi, komandrindas rīks osc un darbvirsmas pārlūks osc-gui, ar izvēles klienta puses šifrēšanu, kas objektu saturu paslēpj no krātuves pakalpojuma sniedzēja.

Produkta lapa GitHub Codeberg

pg-migrate
Paralēli pārnes visas lietotāju datubāzes un globālos objektus starp diviem PostgreSQL serveriem un pārbauda rindu skaitu abās pusēs.
pg-maintenance
Dzēš PostgreSQL tabulās rindas, kas vecākas par noteiktu dienu skaitu, vajadzības gadījumā pa daļām.
object-storage-maintenance
Straumējot apvieno vecus objektus, piemēram, audita žurnālus, vienā saspiestā TAR arhīvā.
amqp-bridge
Pārsūta ziņojumus starp diviem AMQP serveriem un pats atjauno savienojumu; izmantojams arī kā bibliotēka ar pielāgotiem ziņojumu pārveidotājiem.
